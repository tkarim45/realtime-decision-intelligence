Realtime Decision Intelligence — Architecture

Detects incidents in service telemetry, works out which ones are worth acting on, and picks the remediation. Six services at 1 Hz through a durable log, on one core, on a laptop.

Ingest and classify, with the boring guarantees actually proven

  • • the durable log implements the Redis Streams contract on an append-only file: append/claim/ack/redeliver map to XADD/XREADGROUP/XACK/XAUTOCLAIM, so swapping in real Redis is one adapter
  • • a mid-stream crash loses 0 of 1200 events, and offline and online features are byte-identical, so train/serve skew is 0.0
  • • features are ratios against each service's own recent baseline, because a 400ms response is fine for a service that always runs at 380ms and a fire for one that idles at 60ms
  • • the class matters, not just the alarm: each of the five calls for a different remediation, and the wrong remediation is worse than none

Knowing what broke is not knowing what to do

  • • conformal prediction attaches a distribution-free coverage guarantee (0.962 at a 95% target) and routes ambiguous sets away from automatic action
  • • for the ~5% the metrics cannot separate, the log line names the failing upstream: macro-F1 goes 0.863 to 0.968 and dependency_failure recall 0.50 to 0.96
  • • a T-learner estimates the incremental effect of each action per event and acts only when it clears the cost: value 245.1 against 206.3 for the best risk baseline, while treating 21% FEWER events
  • • PSI drift alerts on 8% of clean windows against 100% of drifted ones

Findings that overturned the design, each pinned as a test

  • • conformal cannot hedge a CONFIDENTLY wrong model: at P=0.973 the set is not uncertain, so the log reader exists because calibration could not fix it
  • • the anomaly detector had to leave the hot path (5.9ms per call, 186× cheaper batched) and then leave the thread, because co-location inflated p99 2.4× from uncounted work
  • • a per-class uplift table was too coarse to act on: 108.6 became 245.1 once conditioned on features, and the same risk threshold scores 206.3 at the top 10% and −104.9 at the top 25%
  • • honest gaps: the telemetry is synthetic, and the live-model reader is written but unrun, so the log-reading numbers come from a deterministic offline reader
